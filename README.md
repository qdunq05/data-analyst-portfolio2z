# IT Recruitment Analytics Dashboard | Power BI

## Mô tả
Dashboard phân tích dữ liệu tuyển dụng ngành IT, theo dõi các KPI về mức lương, kỹ năng và xu hướng tuyển dụng.

## Công cụ sử dụng
Power BI, Power Query, DAX

## Nội dung thực hiện
- Làm sạch và biến đổi dữ liệu bằng Power Query
- Xây dựng Data Model dạng Star Schema
- Xây dựng DAX Measures theo dõi KPI tuyển dụng
- Thiết kế Dashboard tương tác trực quan hóa xu hướng tuyển dụng
